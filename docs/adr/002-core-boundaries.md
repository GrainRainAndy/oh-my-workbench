## 随包快捷入口的本机入口库

快捷入口列表保存在插件自己的 `launcher.sqlite`，由版本化服务 `workbench.launcher.library@1.0.0` 提供读写和订阅。窗格重建及工作区复制共用同一本机库。库内应用及文件夹只保存引用、类型与显示名称，系统选取结果和文件身份仍由宿主核对。整机备份包含此数据库。

仍存在于旧布局的固定项在该视图首次读取时合并。已删除的引用保留删除记录，避免旧布局恢复该项。历史上已关闭且没有可读取布局记录的入口需重新添加。
