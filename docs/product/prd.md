# 校准 PRD · 工程评审稿

状态：架构方向与桌面默认行为已确认；业务细项和性能预算仍按各自状态管理。标签含义见 [入口](../README.md)，决策来源见 [台账](decisions.md)。

## 定位与成功条件

C：Desktop-first、Local-first、Plugin-based 个人工作台，用于办公、学习、项目和本地工具。首版 macOS，独立桌面应用方向；Web UI 不等于浏览器标签页产品。宿主管理运行、布局、持久化协调、系统能力与显式协作，业务尽可能属于插件。

M0 成功：第三个验证插件仅通过公开 SDK 接入，无宿主业务分支；多实例、无窗后台、恢复和故障路径可验收。M1 成功：独立日程/待办及至少一个真实本地工具可日常使用，交付可安装应用和恢复说明。工具数量属于 P，待确认。

## 已确认的产品默认行为（C）

登录自启动默认关闭；用户开启后登录启动不弹主窗口。菜单栏默认开启，可关闭，Dock 保持可唤回。手动启动、Dock 激活、菜单“打开”与热键均显示/聚焦最近工作区；热键默认未绑定、由用户设置，重复触发不隐藏窗口，冲突提示且不抢占。主窗口关闭执行草稿检查并销毁窗口释放 UI，宿主后台保留；重新打开重建视图。若性能试验证明隐藏更适合，可重评窗口实现，但不能改变“关闭不退出”。

Cmd+Q：无进行中操作则刷盘退出；有任务/未保存输入则允许取消退出或确认停止并退出，宽限后记录 interrupted/unknown。系统关机/强杀不能依赖确认框，应靠持续持久化恢复。睡眠不视为退出，唤醒重新核对时间、任务、网络；不承诺精确后台计时或自动唤醒设备。

## M1 最低业务范围提案

日程：多日历、事件 CRUD、全天/定时/跨日、月/周/列表、基本提醒、本地持久化；重复按日/周/月/年、间隔与结束条件、单次例外/整组编辑为旧稿 L，建议纳入但须开工前冻结。复杂 RRULE、邀请、双向同步后续。待办：清单 CRUD/排序/归档、事项 CRUD、完成恢复、备注/到期/优先级、今天/计划内/完成视图、本地持久化；子任务、标签、重复任务暂不作为 M1 门槛。清单不是宿主项目。

工具：配置已有端点、能力检查、选文件、提交、关窗继续、结果找回/编辑/导出。query/cancel/格式/时间戳按后端实际能力呈现；不安装模型。Whisper 或 OCR 哪个先实接由现有服务可用性决定，M1 开工前确定。项目、资料、校园、Apple 同步、Agent 会话恢复后续独立规格；Demo 的随手记也不自动纳入 M1。

## 非功能预算与非目标

旧稿 N01/N02 暂存为 L：Apple Silicon 32GB，冷启至可操作≤3s、8窗格恢复≤5s、暖切区 p95≤500ms；拖动 p95≤32ms；空壳全进程 RSS≤500MB、8轻视图≤900MB。未实测、未冻结。P 增加空闲 CPU/唤醒/长期增长报告与无窗测量，数值由 Spike 后确认，不以“轻量”代替证据。

保存确认后应通过强杀恢复；损坏保留原件，迁移失败不清库；本地日程/待办离线可用。控件键盘可达、焦点可辨、支持缩放及辅助技术；自定义 UI 同样遵守。

C 非目标：宿主标签组、退出后守护。L 建议暂缓：云同步、多账户、协作、公开市场、不可信插件安全平台、浮动/跨窗口拖拽、完整文件管理器、内嵌任意网页、通用 Agent 框架。移动端仅保留数据/协议复用可能，不承诺直接运行桌面插件。
