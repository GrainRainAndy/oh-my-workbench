工作台与原生插件的四种方向

打开最新组合稿，体验自适应时间网格、行内新建待办和可自定义的快捷入口。

四个版本共享同一组日程、待办和快捷入口，也都保留递归分屏。差异在于信息排列、编辑方式和操作重心，而不只是配色。建议使用 1280 × 800 或更大的窗口比较。

方案 A

原生分栏

最接近 macOS Calendar 与 Reminders。周日程时间网格配待办、入口上下分栏，编辑使用居中的轻量表单。学习成本最低，适合作为稳妥基线。

方案 B

今日议程

把一周日期压缩成选择条，以时间顺序阅读当天安排。日程和待办都在原位置展开编辑，减少窗口切换；更从容，但同一时间展示的日程较少。

方案 C

月历主从

左侧月历负责定位日期，下方显示选中日，待办和入口各占一列。适合先做月度计划再处理当天内容；窄窗口下三列会更紧凑。

方案 D

紧凑搜索

快捷入口变成顶部搜索栏，日程和待办使用紧凑列表。按 / 聚焦搜索，方向键选择，回车原位打开。操作路径最短，但时间安排不如网格直观。

先比较操作模型

分别点击同一项日程和待办，体验 A/C 的弹出编辑与 B/D 的行内编辑。后者保留上下文，前者能容纳更完整的字段。

再检查分屏

拖动窗格分隔线，或用方向键调整。窗格右上角支持切分、替换、最大化和关闭；关闭窗格不会删除演示业务数据。

状态可以带过去

四版通过浏览器本地存储共享修改。切换页面后继续比较；点顶部“重置演示”可还原。系统应用与文件夹不会真的启动。
