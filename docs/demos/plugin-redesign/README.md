# 插件核心与三个原生插件：四套交互方案

[打开方案索引](index.html) · [组合稿对应的产品重构方案](../../plans/frontend-redesign.md)

[打开最新组合稿](workbench.html)。这是可单独复制、离线打开的完整 HTML。拖动日程右边界可切换一日、三日、五日和整周。五日视图覆盖选中日的前一天至后三天。日程内横滑、横向拖动或按住 Shift 滚轮可平移到相邻时段。待办标题旁的加号支持连续录入。快捷入口的「添加入口」可勾选插件，也可添加应用或文件夹的演示入口。组合稿使用独立的浏览器本地存储，可从工作区标题右侧的菜单重置。

四版都是待选择的 HTML 设计稿，不修改当前产品代码或既定设计规范。页面无外部依赖，可直接用现代浏览器打开；不需要构建或启动服务。

## 版本对比

| 版本 | 主要布局 | 编辑方式 | 适用倾向与取舍 |
| --- | --- | --- | --- |
| [A · 原生分栏](native.html) | 左侧工作区导航；周日程时间网格；待办与快捷入口上下分栏 | 日程和待办使用居中表单；时间块直接表达开始时间与时长 | 最接近 macOS Calendar / Reminders，学习成本最低。重叠日程在窄列中需要点开读取完整标题。 |
| [B · 今日议程](today.html) | 一周日期选择条；当天事项按时间顺序排列；右侧保留待办和入口 | 点击日程或待办后在原位置展开，保存后回到列表 | 上下文连续，适合围绕“今天”处理工作。没有周网格的时长比较能力，同日多项日程需要滚动。 |
| [C · 月历主从](planner.html) | 月历与选中日议程在左，待办和快捷入口各占一列；深色表面 | 选择日期更新下方议程；详情使用完整表单 | 适合先看月度安排再处理单日内容。三列在窄窗口中更紧凑，月历事件标题只能保留短摘要。 |
| [D · 紧凑搜索](compact.html) | 顶部搜索型快捷入口；下方日程、待办双栏列表；省略常驻侧栏 | 搜索、打开和行内编辑为主；按 `/` 聚焦搜索，方向键选择，回车打开 | 高频操作路径短，窗口内容密度高。日程时长与重叠关系不如 A 的时间网格直观。 |

## 已实现交互

- 工作区切换、新建、重命名、复制布局与删除；删除工作区不删除插件数据。
- 窗格左右/上下切分、替换、关闭、最大化与还原；关闭窗格不删除业务数据。
- 分隔线拖动、方向键调整、双击均分；侧栏宽度也可调整。
- 日程新建、编辑、删除、日期切换与结束时间校验；A 支持日/三日/周切换，C 支持日历显隐。
- 待办新增、完成/恢复、筛选、详情编辑与删除。
- 快捷入口搜索、添加与移除；插件单击原位打开，右键可选择“在旁边打开”。
- 修改通过浏览器 `localStorage` 在四版之间共享；顶部“重置演示”还原初始数据和布局。
- 键盘焦点样式、菜单方向键导航、`prefers-reduced-motion`、减少透明度和增强对比度适配。

## 比较建议

先以 A 为基线，重点判断 B 的行内编辑是否比弹出表单更顺畅。若主要使用月计划，再比较 C；若快捷入口是最高频入口，再比较 D。最终也可以组合，例如采用 A 的时间网格与 B 的行内详情，而不必整版照搬。

## 范围与限制

这是交互证据，不是生产实现。数据固定以 2026-11-24 为“今天”；刷新后保留浏览器中的修改，清除站点数据会还原。不会启动真实应用、打开文件夹、访问插件服务或修改系统设置。未验证真实后端、辅助技术完整流程和 macOS 原生窗口行为。
