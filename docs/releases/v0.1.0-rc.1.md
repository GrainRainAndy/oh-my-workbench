Oh My Workbench v0.1.0 的首个发布候选版，适用于 Apple Silicon Mac。

## 这版包含

- 本地工作区支持横竖分屏、窗格调整和插件多实例。支持浅色、深色与跟随系统。
- 快捷入口统一管理插件、应用与文件夹，多个窗格共享已保存的入口。
- 日程按窗格宽度显示 1、3、5 或 7 天，支持连续横移和逐日吸附。
- 待办支持清单、日期和优先级，回车可在清单内连续录入。
- 提供插件管理、任务中心和工作台备份。

## 安装与验证

1. 下载 `OhMyWorkbench-0.1.0-rc.1-arm64.dmg` 与 `SHA256SUMS.txt`。把两者放在同一目录，可运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。
2. 打开镜像，把 Oh My Workbench 拖到 Applications，再从「应用程序」打开。

候选版采用 ad hoc 签名，Developer ID 签名和 Apple 公证留待正式发布。如遇安全提示，可参考 [Apple 的应用打开说明](https://support.apple.com/zh-cn/102445)。

本版本在 Apple Silicon、macOS 27.0.1 上执行源码和包内无窗口测试。其他 macOS 版本、实体触控板及辅助功能的前台实测仍在验收范围内。构建提交及测试结果见附件 `build.json` 和 `tests.log`。
