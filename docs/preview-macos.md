# macOS 预览版使用说明

当前前端重构预览面向 Apple Silicon。[打开 Us3l7n 应用](<../release/macos-arm64-Us3l7n/Oh My Workbench.app>)。从访达打开应用可试用本轮重构。关闭窗口后可从菜单栏重新打开，选择退出会结束应用及后台任务执行。[日程连续横移验收](qa/evidence/runtime-progress.md#日程连续横移) · [侧栏图标验收](qa/evidence/runtime-progress.md#同步侧栏品牌图标)

在项目根目录运行 `npm run package:mac -- --keep-previous` 可重新打包并保留本机已有构建。出包时执行了 `codesign --verify --deep --strict`。本地应用使用 ad hoc 签名，Developer ID 签名和公证属于正式发布验收。

## 后台复核

在仓库根目录运行 `npm run test:headless -- "<待验证的 .app 路径>"`。前两组检查当前源码的选择器、快捷入口和时间轴；产品版的后四组以指定应用的 Electron Node 模式运行测试桥、SQLite 仓库和插件后台子进程，读取包内界面资源，验证工作区、插件服务、业务库恢复和后台任务。开发版可通过 `npm run package:mac -- --with-fixtures` 生成，另含验证插件及其服务与后台导出回归。各组使用临时配置，依次启动无窗口 Chrome。类型检查、插件边界与单元测试使用 `npm test`。

## 保存和恢复

1. 在「插件管理」的「工作台备份」中选择「创建本机备份」。操作完成后可通过「在访达中显示」定位备份。
2. 需要恢复时展开「备份记录」，按日期选择「恢复此备份」。确认窗口会列出将恢复的插件数据库，以及备份时尚未创建数据库的插件。
3. 核对后选择「确认恢复」。工作台先备份当前数据，再切换到恢复副本。工作区、插件设置和任务记录随备份恢复，凭据沿用本机当前状态。
4. 旧数据库可在对应插件下从该插件的「···」菜单选择「检查数据升级」。升级前生成快照并在副本上执行迁移，失败时可从提示定位升级前的备份。

## 随包许可

在访达中对应用选择「显示包内容」，打开 `Contents/Resources/Licenses`。其中包含 Electron、React、React DOM、Scheduler 的许可证和 Chromium 第三方许可清单。

真实 Whisper 转写仍待接入。系统实测范围及各项限制见[验证记录](qa/evidence/runtime-progress.md)。

## 使用安装镜像

运行 `npm run package:mac -- --dmg` 可同时生成压缩 DMG。打开镜像，将 Oh My Workbench 拖到旁边的 Applications，再推出镜像并从「应用程序」启动。分发预览镜像沿用应用的本地 ad hoc 签名。

新构建还在同一许可目录提供 renderer-licenses.md，按实际进入前端构建的依赖列出版本和许可文本。

## 快捷入口

创建工作区时选择「快捷入口」作为初始视图，也可以在空窗格中选择它。点右上角的「添加入口」后选择插件、应用或文件夹。使用对象菜单移除入口，或选择「在旁边打开」保留快捷入口窗格。

首次启动还可以直接点击欢迎页的「快捷入口」。工作台会创建「我的工作台」并进入入口窗格，之后可以从工作区菜单重命名。

新建日程窗格可查看按宽度自适应的时间表。点击事件打开记录详情，或使用「新建日程」打开录入控件。窗口左上方可收起侧栏。
