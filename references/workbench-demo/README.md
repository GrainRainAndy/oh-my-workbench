# 个人工作台 · 交互 Demo 0.1

这是一份用于评审产品形态的浏览器原型，不是完整桌面应用、正式插件宿主或产品 MVP。基于本会话确认的工作区中心、多窗格、多工作区、插件 UI、视图与任务解耦等要求制作。

## 打开方式

直接用浏览器打开 `index.html`。这是无构建步骤、无依赖、无远程字体或脚本的自包含网页。若聊天附件预览器只显示源码或不执行脚本，请保存 HTML 后用桌面浏览器打开。

本次没有部署公网网址。`index.html` 可以作为静态站点入口部署到你自己的托管环境；无需服务端接口。当前演示不依赖外部网络。

## 建议体验顺序

1. 在「日常」「研究与项目」「资料处理」之间切换，比较不同布局。
2. 点击任一窗格右上角的 `···`：左右 / 上下切分，选择插件。拖动分隔线调整比例，拖动标题左侧手柄交换窗格，也可用菜单交换。
3. 在「布局」菜单中复制、重命名或删除工作区，检查业务数据是否仍然共享。新增工作区可从空白或模板开始。
4. 新增和完成待办；点击日程块编辑，点击周历空白处或月历日期新增日程。
5. 在本地工具中开始模拟转写，关闭窗格、切换工作区，然后打开任务中心。完成后复制、导出或加入常用入口。
6. 在插件管理中停用日程，再重新启用，观察占位和数据恢复。切换浅色 / 深色主题。

## 已实现的交互

| 范围 | 行为 |
|---|---|
| 工作区 | 新建、切换、重命名、复制、删除；布局导入 / 导出 |
| 窗格 | 递归左右 / 上下切分、调整比例、更换视图、关闭、最大化 / 恢复、菜单交换 / 拖拽交换、布局撤销 |
| 视图 | 同一插件多实例；待办筛选独立、业务数据共享；停用后保留占位 |
| 日程 | 周 / 月 / 议程视图，单日定时事件增删改，时间合法性验证 |
| 待办 | 新增、编辑、删除、完成 / 恢复、清单、日期、普通 / 较高优先级、筛选 |
| 工具 | Whisper / OCR 固定示例，进度、取消、任务中心、结果复制 / 导出 / 加入入口 |
| 资料入口 | 文件 / 目录 / 网页 / 会话引用；新增、移除、复制；自定义 http(s) 网页可明确点击外部打开 |
| 随手记 | 可编辑，多个视图共享笔记 |
| 校园动态 | 仅示例展示，不连接校园平台 |
| 全局 | 命令面板、主题切换、浏览器本地存储、重置示例 |

## 边界与隐私

- 初始课程、待办、日程和文件路径都是示例，不是从个人账号读取的真实数据。演示日期固定为 2026-11-18；「今天」按钮回到这个示例日期。
- 没有接入 Apple Calendar、Reminders、校园平台、实际 OCR / Whisper 服务或任何 Agent。
- 选择音频 / 图片时只使用文件名称等元数据，不读取内容、不上传、不推理。结果为固定示例文本。导入布局时需要读取用户选择的 JSON 文件。
- 工具任务只是当前页面内的计时模拟。关闭工具窗格或切换工作区不取消任务；关闭、刷新整个页面则中断未完成任务。重新打开时显示中断，不伪装继续执行。
- 插件启停、视图注册和跨视图协作是 UI / 状态层演示；没有动态代码装载、独立插件进程、安全沙箱或实际版本化服务 Broker。
- 使用 `localStorage` 保存布局和编辑内容，范围仅为当前浏览器与该页面来源。不提供同步或完整业务数据备份。布局导出不包含日程、待办、笔记或凭据。
- 一些内嵌预览器、隐私模式或文件页面策略可能限制存储。保存失败时状态栏会明确提示，当前页面仍可交互。
- 不同来源、浏览器、文件路径之间不保证共享存档。不要输入敏感内容；不要把 Demo 当作日常数据的唯一副本。
- 不提供宿主级窗格标签页。Whisper / OCR 的切换只属于工具插件内部界面。
- 为控制原型复杂度，最多 20 套工作区、每套 12 个视图、同时 4 个模拟任务；这些是 Demo 限制，不是对正式 PRD 的修改。
- 以桌面为主；窄屏保留桌面布局并允许工作区滚动，不代表移动端产品方案。

## 快捷键

`⌘ / Ctrl K`：搜索与命令；`⌘ / Ctrl Z`：在非输入框中撤销布局；`Esc`：关闭弹窗、菜单、任务中心或退出最大化。分隔线可以 Tab 聚焦后用方向键调整。

## 测试记录

`test-results.json` 记录了 23 组浏览器交互检查，运行于 Chromium + Playwright，包括分屏、交换、共享数据、工作区复制 / 删除、任务跨视图运行、插件停用恢复、导入 / 导出和输入验证。测试未发现未捕获的 JavaScript 错误。

执行环境的浏览器禁止文件 / 回环网址导航，所以测试用 `page.set_content` 注入本文件，并用与 `localStorage` 接口兼容的内存替身测试序列化和恢复。**未验证真实 `file://` 页面存储持久性、Safari、Firefox 或公网部署。**截图也来自该测试环境；未在交付 HTML 中加入存储替身。

`test_demo.py` 是可复现的测试脚本，需要 Python Playwright 与 Chromium。其中 `/usr/bin/chromium` 是本次执行环境的浏览器位置；在其他环境运行时修改为本机 Chromium 路径，或使用 Playwright 安装的浏览器。
